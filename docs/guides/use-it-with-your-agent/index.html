Use it with your agent

Agents can work at two levels: inside the search, proposing each proof step, or outside it, driving the command line for you.

Let Codex propose the steps

Authenticate the Codex CLI with a ChatGPT login or an API key, check the setup, then search with the Codex proposer.

codex login
node formal/src/cli.mjs doctor --proposer codex
node formal/src/cli.mjs solve benchmarks/tier1.json \
  --id conjunction_commutation --proposer codex --compiler worker \
  --model-token-budget 50000

Each call runs in a separate temporary directory with execution tools, apps, plugins, web search and configured MCP servers disabled. The agent returns structured tactic or have proposals. Only the token usage the CLI actually reports is counted, and a response that would exceed the allowance is rejected. The allowance is an admission threshold, not a billing cap: a request already in flight can still cost more. Use --model to pick a model explicitly.

Plug in any other model

Any program that reads one JSON request on standard input and writes proposals to standard output can be the proposer. It is launched directly from an argument list, without a shell.

node formal/src/cli.mjs solve my-lemma.json \
  --proposer-command '["node","/absolute/path/to/my-proposer.mjs"]' \
  --model-token-budget 8000

The request carries the current goal, its hypotheses, the imports, recent feedback and the remaining budget. The response lists proposals and the tokens actually used:

{
  "proposals": [
    {"tactic": "constructor"},
    {"kind": "have", "name": "aux", "type": "P"}
  ],
  "modelTokens": 120
}

The runtime README documents the full request and response format.

Let a coding agent drive the CLI

The CLI reads a JSON manifest and prints a JSON result, so any coding agent that can run terminal commands can operate it. Point your agent at the repository and ask:

Write my lemma as a Formal Verify Anything problem manifest, run
`node formal/src/cli.mjs solve` on it with `--proposer codex`, and show me the
accepted proof, the attempts it pruned, and the kernel audit.

Who has the final word

Whatever proposes the steps, the same gate applies: two fresh compilations and a kernel audit of every dependency. An agent's confidence never turns into an accepted proof by itself.
